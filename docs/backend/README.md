# Свидетельства проверки движка

- `release-audit.json`: SHA-256 опубликованных архивов и извлечённых бинарников
  v2.1.0, результат Windows-проверки CLI, SOCKS5 handshake и завершения процесса.
- `build-audit.json`: локальная сборка закреплённой ревизии, результаты upstream
  tests/vet и опись лицензий модулей для трёх платформ. Локальные сборки отличаются
  от релизных флагами/меткой версии и не используются загрузчиком приложения.
- `AWG-WIREPROXY-LICENSE.txt`: неизменённый ISC LICENSE из проверенной ревизии.

`distributionApproved: false` в отчёте означает, что полная подготовка нашей
перепубликации пакетов с NOTICE/SBOM ещё не завершена. Сам upstream имеет ISC.
Приложение скачивает архивы непосредственно у автора и сохраняет LICENSE рядом
с движком. Отчёты не подтверждают внешний VPN, отсутствие DNS-утечек или нативный
запуск на Linux/macOS.
