# Проверки каркаса

Локальный прогон 18 октября 2026 года, Windows x64. Flutter 3.47.7, Dart 3.13.5, Go 1.27.0.

| Проверка | Результат |
| --- | --- |
| flutter analyze | Без замечаний |
| flutter test | Пройден тест отключённого подключения и переключения темы |
| flutter build windows --release | Успешная сборка |
| flutter run -d windows | Приложение запущено в Debug |
| Hot restart | Успешно, 345 мс; затем приложение закрыто |
| go test ./... | Пройден тест аргументов с пробелами и запрета внешних/некорректных адресов |
| go vet ./... | Без замечаний |
| go build ./cmd/proxy-engine | Успешная сборка |
| --capabilities | JSON protocolVersion=1, status=scaffold, canStart=false |
| git diff --cached --check | Без ошибок пробелов |

Не проверены: нативные сборки macOS/Linux, GitHub Actions на удалённых runners, визуальная доступность на реальных дисплеях, VPN-трафик, импорт и управление процессами. Эти функции либо требуют другой ОС/сервера, либо ещё не реализованы. Успешный запуск и hot restart не заменяют визуальную приёмку интерфейса.

В репозитории сохраняются исходники и lockfile; бинарники, build-каталоги и пользовательские VPN-профили исключены из Git. CI не публикует релиз и не подключается к VPN.
