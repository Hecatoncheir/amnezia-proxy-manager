# Проверки каркаса

## Подготовка M1 и отдельного runtime — 18 октября 2026 года

В рабочем коде после v0.1.1 подготовлены проверка GitHub-каталога backend при
запуске, выбор совместимой версии, загрузка/проверка/активация runtime. Реальный
каталог `synacker/amnezia-proxy` пуст: приложение показывает отсутствие совместимого
выпуска. Через Flutter Driver проверено это состояние, hot reload успешен,
ошибок Dart/Flutter нет.

Локально: `flutter analyze`, 33 теста Flutter, Windows Release-сборка; Go tests/vet
с настоящим `BACKEND_TEST_BINARY`, CLI `--inspect-backend` подтвердил хеш и ревизию.
Upstream собран с CGO=0 под Windows amd64, Linux amd64 и Darwin arm64; тесты/vet
исполнены только нативно на Windows. Снимок сборок: `backend/build-audit.json`.

`tool/engine_install_probe.dart` проверил Windows-runtime настоящим upstream EXE:
контролируемый HTTP-каталог → скачивание → SHA-256 → PE x64 → CLI `-h` →
активация → повторная проверка. Результат `passed: true`, `status: ready`;
это не загрузка опубликованного GitHub Release и не VPN-соединение.

M1 не завершён: не подтверждены разрешение распространения upstream, реальный
VPN-трафик и нативный запуск backend на macOS/Linux. Предлагаемый контракт
`engine.json` ещё не согласован с upstream. Новый релиз приложения не создавался.
Отчёт и дальнейшие шаги: [UPSTREAM.md](UPSTREAM.md), [ENGINE-RUNTIME.md](ENGINE-RUNTIME.md).

## Установщики, обновление и окно — 18 октября 2026 года

В текущей рабочей копии добавлены Setup, DMG и RUN, проверка стабильных выпусков
в настройках, загрузка с докачкой и SHA-256, установка Windows с перезапуском.
Опубликованный v0.1.0 остаётся первоначальным выпуском без установщиков.

Локально проверены:

- `flutter analyze` без замечаний, 25 успешных тестов Flutter, четыре теста Python
  подготовки версии, `actionlint` обоих workflow, синтаксис оболочечных упаковщиков.
- Release-сборка Windows и Inno Setup 6; распространяемые библиотеки MSVC включены
  в bundle, чтобы установке не требовалась Visual Studio.
- `packaging/check-windows-update.ps1`: настоящее восстановление геометрии окна
  после перезапуска, установка поверх тестовой копии, замена EXE и Dart AOT,
  запуск новой копии и сохранение постороннего файла.
- Экран настроек в окне 380×560 с масштабом текста 1.4; главный экран и проверка
  GitHub Releases через Flutter Driver на запущенном приложении. Hot reload успешен,
  ошибок Dart/Flutter после проверки нет. Текущий GitHub-релиз без установщиков
  корректно отображается как отсутствие подходящих пакетов.
- Общий PNG с прозрачностью, семь размеров ICO, семь размеров AppIcon macOS;
  значок используется в шапке, Windows-ресурсах, установщике, macOS и Linux.

В Windows runner исправлен порядок завершения: явный `window.Destroy()` перед
`CoUninitialize()` устраняет аварию при завершении через WM_QUIT из window_manager.
Проверка реального перезапуска дополнительно требует нулевого кода завершения.

Нативная сборка/установка DMG и Linux RUN, доверенная подпись издателя и новый
удалённый CI для этих изменений пока не подтверждены. Linux-тест оболочечного
установщика выполняется на Linux в CI и пропускается локально на Windows.
Старые результаты ниже относятся к указанным коммитам и прежним состояниям.

## Первоначальный локальный прогон

Локальный прогон 18 октября 2026 года, Windows x64. Flutter 3.47.7, Dart 3.13.5, Go 1.27.0.

| Проверка | Результат |
| --- | --- |
| flutter analyze | Без замечаний |
| flutter test | Пройден тест отключённого подключения и переключения темы |
| flutter build windows --release | Успешная сборка |
| flutter run -d windows | Приложение запущено в Debug |
| Hot restart | Успешно, 345 мс; затем приложение закрыто |
| go test ./... | Пройден тест аргументов с пробелами и запрета внешних/некорректных адресов |
| go vet ./... | Без замечаний |
| go build ./cmd/proxy-engine | Успешная сборка |
| --capabilities | JSON protocolVersion=1, status=scaffold, canStart=false |
| git diff --cached --check | Без ошибок пробелов |

Не проверены: нативные сборки macOS/Linux, GitHub Actions на удалённых runners, визуальная доступность на реальных дисплеях, VPN-трафик, импорт и управление процессами. Эти функции либо требуют другой ОС/сервера, либо ещё не реализованы. Успешный запуск и hot restart не заменяют визуальную приёмку интерфейса.

В репозитории сохраняются исходники и lockfile; бинарники, build-каталоги и пользовательские VPN-профили исключены из Git. CI не публикует релиз и не подключается к VPN.
