# Интеграция upstream

Источник: https://github.com/synacker/amnezia-proxy
Ревизия, просмотренная 18 октября 2026 года: f5a7912dba8b128ae5c1a3f68a06be7c1668b908.

Это самостоятельный Go package main. В просмотренном go.mod указан Go 1.25.0 и amneziawg-go/v3 v3.1.20260828. Мы не импортируем package main как библиотеку и не копируем его исходники.

Адаптер формирует аргументы -config, -socks-listen и -http-listen для отдельного бинарника. Источником сетевой реализации остаётся upstream. В текущем коммите binary не скачивается, не собирается и не запускается.

Перед интеграцией:
1. Проверить LICENSE/разрешение автора на выбранной ревизии и условия зависимостей. Наличие публичного GitHub-репозитория само по себе не даёт права распространять его код.
2. После разрешения собрать зафиксированную ревизию на каждой ОС, записать hash и лицензии.
3. Проверить совместимость CLI и готовность listeners, перехват ошибок и завершение дерева процессов.
4. Реализовать безопасную передачу профиля. Текущий адаптер передаёт только путь, не ключи; путь тоже может содержать приватные сведения.
5. Проверить поведение реального туннеля и ограничения протоколов.
