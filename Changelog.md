# История изменений

## Unreleased

- Подготовлена отдельная загрузка совместимого AmneziaWG backend при запуске,
  проверка размера, SHA-256, архитектуры и CLI; хранение runtime вне установки UI.
- Проверена ревизия upstream, подготовлены три локальные сборки и опись зависимостей.
- Добавлена диагностика `proxy-engine --inspect-backend` по хешу и Go build info.

Ограничения: в upstream пока нет лицензии и GitHub Releases; готовность настоящей
загрузки из репозитория и работа VPN пока не подтверждены.

## v0.1.1 — 2026-10-18

- Установщик Windows Setup с обновлением поверх существующей копии и перезапуском.
- DMG для macOS arm64 и установочный `.run` для Linux x64; переносимые архивы сохранены.
- Проверка стабильных выпусков в настройках, описание изменений, загрузка с прогрессом
  и докачкой, проверка размера и SHA-256 перед установкой.
- Установка обновления из интерфейса Windows; инструкции установки для macOS и Linux.
- Начальное окно 540×840; сохранение размера, положения и развёрнутого состояния.
- Общая иконка приложения, окна, установщиков и ярлыков в палитре Gruvbox.
- Убраны поясняющие абзацы с главного экрана; подзаголовок заменён на «ЛОКАЛЬНЫЙ ПРОКСИ».

Ограничения: подключение VPN, импорт профилей и IPC пока не реализованы.
Установщики не имеют доверенной подписи издателя; для macOS и Linux установка обновления выполняется вручную.

## v0.1.0 — 2026-10-18

- Начальный интерфейс Flutter Desktop для Windows, macOS и Linux с темами Gruvbox.
- Диагностический Go CLI и адаптер аргументов upstream.
- Проверки CI, подготовка версии и публикация архивов по тегу.

Ограничения: подключение VPN, импорт профилей и IPC пока не реализованы.
Архивы не подписаны; Go CLI выполняет только диагностику, backend upstream не включён.
