# История изменений

## Unreleased

## v0.1.18 — 2026-10-22

- На macOS фильтрация PF теперь действует всё время полного VPN, в том числе при выключенной защите при обрыве: DNS локального роутера и сокеты с привязкой к физическому интерфейсу больше не обходят туннель. Переключатель определяет сохранение блокировки после обрыва; при его выключении штатно обработанный отказ движка снимает временный фильтр после остановки процессов.
- Нативный захват исходящих пакетов на macOS подтвердил отсутствие DNS/IPv6 на физическом интерфейсе при работающем полном VLESS VPN и после аварии TUN с включённой защитой. Внешний IPv6 в сети проверки недоступен; проверены маршрут IPv6 через TUN и блокировка локального IPv6 multicast.

## v0.1.17 — 2026-10-22

- Исправлен запуск macOS без окна: Flutter инициализируется до скрытия окна; обычный запуск и скрытый старт в трей проверены нативно.
- Исправлена установка загружаемых движков в macOS: DMG-поставка работает вне App Sandbox, который помещал создаваемые движки в карантин и запрещал их запуск. Gatekeeper и SIP не отключаются; проверки SHA-256, архитектуры, конфигураций и системный запрос прав для полного VPN сохранены.
- В CI и сборку выпуска добавлены скачивание, установка и запуск настоящего AWG-движка на macOS; проверка аварийной гибели supervisor теперь выполняется и на macOS.
- Для полного VPN на macOS добавлен временный системный DNS через TUN. Постоянные настройки сетевых служб не меняются; резолвер удаляется при остановке и при аварии supervisor. В CI добавлена нативная проверка его жизненного цикла.
- Первый импорт AmneziaVPN на macOS ожидает подтверждения Связки ключей до трёх минут.
- Нативно на macOS Apple Silicon проверены реальный VLESS через SOCKS5/HTTP и полный VPN: HTTPS 200 без прокси, маршрут TUN, повторное подключение, снятие защиты и восстановление сети. Реальная AWG-сеть, отдельная проверка DNS/IPv6-утечек, сон и смена Wi-Fi остаются вне этого прогона.
- Нативная проверка macOS в CI получает отдельный токен только для GitHub API, не передаёт его на хосты архивов и выводит безопасный отчёт об HTTP-статусах. Время холодной сборки тестового приложения учитывается отдельно от сетевых тайм-аутов.
- Блок VPN стал компактнее: переключатели рядом, короткие подписи, подробности в подсказках; в узком окне и при крупном тексте элементы переносятся.

## v0.1.15 — 2026-10-21

- Общая типографика сайта и приложения: Nunito, Nunito Sans и JetBrains Mono, с локальными файлами шрифтов и лицензиями SIL OFL.
- Добавлен одностраничный сайт GitHub Pages: выбор установщика для трёх ОС, плавная смена платформы, светлая/тёмная тема и интерактивная иллюстрация маршрута.
- Новое оформление по выбранному варианту 03: рукописный логотип Amnezia, иконка с монограммой и 20 округлых SVG-пиктограмм для интерфейса и макетов. Обновлены значки Windows, Linux и macOS.
- Обновлены снимки интерфейса в README; добавлена инструкция по полному VPN и снятию блокировки после сбоя.
- Добавлен переключатель «Пропускать весь трафик через VPN» для Windows x64, Linux x64 и macOS arm64. Локальные SOCKS5 и HTTP-прокси продолжают работать.
- Добавлена отдельная блокировка интернета при обрыве VPN, включённая по умолчанию: WFP в Windows, nftables в Linux и PF в macOS. Предусмотрено ручное снятие блокировки.
- DNS направляется через VPN; параметры TUN и файлы движков проверяются перед запуском. Системные права запрашиваются только для полного туннеля и управления блокировкой.
- В Linux для полного туннеля нужны nftables и polkit. В macOS установка защиты сбрасывает существующие состояния PF; несовместимые правила PF обнаруживаются до подключения.
- Проверки сборок и автоматические тесты не заменяют приёмку с реальными профилями: смена внешнего IP, DNS/IPv6 и аварийные обрывы на каждой ОС ещё требуют сетевой проверки. Подробности — в docs/TUN.md.

## v0.1.3 — 2026-10-18

- Подключение и отключение AmneziaWG/VLESS круглой кнопкой; состояния запуска, отмены, готовности, ошибки и повторного подключения.
- Go supervisor с JSON Lines IPC, повторной проверкой движка, контролем портов и независимой HTTPS-проверкой через SOCKS5.
- Остановка дерева процессов при закрытии/EOF, Windows Job Object, защищённая временная конфигурация и уборка после аварии.
- Отдельные переключатели автозапуска при входе в систему и автоподключения выбранного профиля при запуске приложения; изначально выключены.
- Отдельная загрузка awg-wireproxy v2.1.0 (ISC) и Xray v26.7.28 (MPL-2.0) с проверкой SHA-256 архивов и бинарников, архитектуры и CLI; runtime хранится вне установки.
- Круговой индикатор реального процента скачивания в цветах темы, повторное использование установленного движка без сети.
- Импорт .conf/.vpn/.json, vpn:// и vless://, поддержка цепочек VLESS; проверка конфигурации настоящим движком.
- Явный импорт выбранного сохранённого профиля установленной AmneziaVPN на Windows без создания новой конфигурации Premium.
- Системное защищённое хранение ключей, выбор и удаление профилей; временный режим при недоступности хранилища.
- Профили и движки перенесены в меню. На главном экране — подключение и скорость; круглая кнопка терракотовая при отключении.
- Квадратное начальное окно 540×540 с сохранением пользовательского размера и положения.
- Обновлены TODO, аудит движков, документация IPC и протоколы нативных проверок.

Проверено на Windows: реальный VLESS с HTTPS через SOCKS5, повторное подключение, запуск/остановка AWG с синтетическим профилем, 100 циклов управления тестовыми процессами и аварийные сценарии. Xray v26.7.28 помечен upstream как prerelease: разрешён только конкретный закреплённый выпуск.

Ограничения: реальная AWG-сеть, нативные VPN-сценарии macOS/Linux и автозапуск после входа в ОС ещё требуют проверки. Скорость пока не измеряется; системный прокси не меняется. Пакеты не имеют доверенной подписи издателя/notarization.

- Исправлена Windows-проверка сохранения квадратного окна: минимальный размер берётся из общей модели; ошибка завершает процесс с диагностикой, журналы сохраняются в CI.
