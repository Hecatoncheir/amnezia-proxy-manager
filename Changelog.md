# История изменений

## Unreleased

## v0.1.9 — 2026-10-19

- Исправлен показ окна после запуска со скрывающим системным флагом Windows; проверка перезапуска дожидается видимости окна перед сохранением размеров.
- Скрытый запуск сохраняет развёрнутое состояние и геометрию окна; нативная проверка охватывает восстановление и сохранение максимизации.
- Настройка «Автозапуск свёрнутым в трей», значок приложения и меню открытия, сворачивания и выхода; при недоступном трее окно остаётся видимым.
- Отдельный признак автозапуска в Windows/macOS/Linux; обычный запуск ярлыком открывает окно, старые записи автозагрузки распознаются.
- Чтение выбранного профиля AmneziaVPN на Linux из стандартного Qt INI и на macOS через CFPreferences/Keychain; автоматическое обнаружение и ручной импорт доступны на трёх ОС. Реальные установки macOS/Linux ещё требуют нативной проверки.
- В README рекомендовано сначала настроить официальную AmneziaVPN и проверить соединение, затем использовать менеджер самостоятельно.


## v0.1.6 — 2026-10-18

- Выбор портов SOCKS5 и HTTP на главном экране, сохранение пары и использование при ручном/автоматическом подключении.
- Повторная проверка диапазона и разных портов в supervisor; выбранные номера применяются к AWG и Xray и к HTTPS-проверке.
- Обновлены скриншоты главного экрана и инструкция по локальным портам.

## v0.1.5 — 2026-10-18

- Состояние подготовки подключения перенесено в PreparationCubit; виджет упрощён, используется общий индикатор загрузки.
- Измерена сложность изменённого блока, добавлены правила разработки и воспроизводимая инструкция проверки.
- Автоматический поиск сохранённого профиля AmneziaVPN при первом запуске в Windows; проверка и защищённое сохранение по нажатию подключения.
- Автоматическая загрузка совместимого движка при импорте и подключении, с процентами на главном экране и проверкой SHA-256.
- Подробная пользовательская инструкция в README с девятью скриншотами интерфейса.


## v0.1.3 — 2026-10-18

- Подключение и отключение AmneziaWG/VLESS круглой кнопкой; состояния запуска, отмены, готовности, ошибки и повторного подключения.
- Go supervisor с JSON Lines IPC, повторной проверкой движка, контролем портов и независимой HTTPS-проверкой через SOCKS5.
- Остановка дерева процессов при закрытии/EOF, Windows Job Object, защищённая временная конфигурация и уборка после аварии.
- Отдельные переключатели автозапуска при входе в систему и автоподключения выбранного профиля при запуске приложения; изначально выключены.
- Отдельная загрузка awg-wireproxy v2.1.0 (ISC) и Xray v26.7.28 (MPL-2.0) с проверкой SHA-256 архивов и бинарников, архитектуры и CLI; runtime хранится вне установки.
- Круговой индикатор реального процента скачивания в цветах темы, повторное использование установленного движка без сети.
- Импорт .conf/.vpn/.json, vpn:// и vless://, поддержка цепочек VLESS; проверка конфигурации настоящим движком.
- Явный импорт выбранного сохранённого профиля установленной AmneziaVPN на Windows без создания новой конфигурации Premium.
- Системное защищённое хранение ключей, выбор и удаление профилей; временный режим при недоступности хранилища.
- Профили и движки перенесены в меню. На главном экране — подключение и скорость; круглая кнопка терракотовая при отключении.
- Квадратное начальное окно 540×540 с сохранением пользовательского размера и положения.
- Обновлены TODO, аудит движков, документация IPC и протоколы нативных проверок.

Проверено на Windows: реальный VLESS с HTTPS через SOCKS5, повторное подключение, запуск/остановка AWG с синтетическим профилем, 100 циклов управления тестовыми процессами и аварийные сценарии. Xray v26.7.28 помечен upstream как prerelease: разрешён только конкретный закреплённый выпуск.

Ограничения: реальная AWG-сеть, нативные VPN-сценарии macOS/Linux и автозапуск после входа в ОС ещё требуют проверки. Скорость пока не измеряется; системный прокси не меняется. Пакеты не имеют доверенной подписи издателя/notarization.

- Исправлена Windows-проверка сохранения квадратного окна: минимальный размер берётся из общей модели; ошибка завершает процесс с диагностикой, журналы сохраняются в CI.

## v0.1.1 — 2026-10-18

- Установщик Windows Setup с обновлением поверх существующей копии и перезапуском.
- DMG для macOS arm64 и установочный `.run` для Linux x64; переносимые архивы сохранены.
- Проверка стабильных выпусков в настройках, описание изменений, загрузка с прогрессом
  и докачкой, проверка размера и SHA-256 перед установкой.
- Установка обновления из интерфейса Windows; инструкции установки для macOS и Linux.
- Начальное окно 540×840; сохранение размера, положения и развёрнутого состояния.
- Общая иконка приложения, окна, установщиков и ярлыков в палитре Gruvbox.
- Убраны поясняющие абзацы с главного экрана; подзаголовок заменён на «ЛОКАЛЬНЫЙ ПРОКСИ».

Ограничения: подключение VPN, импорт профилей и IPC пока не реализованы.
Установщики не имеют доверенной подписи издателя; для macOS и Linux установка обновления выполняется вручную.
