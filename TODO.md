# План реализации

Отметка [x] означает наличие в репозитории, а не готовность продукта. Milestones — план для будущих GitHub Issues; удалённые milestones не созданы.

## M0 — Основа проекта (0.1.0)

- [x] Flutter Desktop runners Windows/macOS/Linux.
- [x] Gruvbox Dark/Light, переходы 180–240 мс, учёт отключения анимации.
- [x] Ограничение ширины основного содержимого, прокрутка.
- [x] Go CLI capabilities и адаптер параметров upstream без запуска процесса.
- [x] Архитектура, ограничения, фиксация upstream revision.
- [x] CI матрица сборки и тестов, gitignore, настройки форматирования.
- [ ] Подтвердить зелёный CI после разрешённого push.
- [ ] Проверить интерфейс на macOS/Linux и масштабах 100/150/200%.
Критерий выхода: три нативные сборки и проверенные тесты; никаких фиктивных индикаторов подключения.

## M1 — Проверка backend и прав распространения

Зависит от M0; блокирует включение upstream в поставку.
- [ ] Установить лицензию исходников upstream и транзитивных зависимостей, получить разрешение при необходимости.
- [ ] Зафиксировать исходники/версию и контрольные суммы сборок, составить NOTICE/SBOM.
- [ ] Собрать upstream на трёх ОС; отдельно оценить x64/arm64.
- [ ] Проверить SOCKS5 TCP CONNECT, HTTP CONNECT и plain HTTP через тестовый сервер.
- [ ] Проверить DNS через туннель, IPv4/IPv6, ошибочный ключ и недоступный endpoint.
- [ ] Подтвердить поддерживаемые версии AmneziaWG и форматы экспорта.
- [ ] Проверить поведение при одновременном запуске AmneziaVPN с тем же ключом; рекомендовать отдельный профиль.
Критерий выхода: воспроизводимые сетевые проверки и документированные условия распространения. UDP ASSOCIATE не обещать без отдельной реализации.

## M2 — Профили и хранение

Зависит от M1.
- [ ] Добавить явный выбор экспортированного файла; ограничить размер и проверить формат до разбора.
- [ ] Поддержать только подтверждённые форматы .conf/.vpn; отклонять неизвестные протоколы.
- [ ] Не запускать директивы PostUp/PostDown или произвольные команды из профилей.
- [ ] Отделить публичные метаданные от ключей; исключить секреты из состояния UI, логов и аналитики.
- [ ] Реализовать Windows Credential Manager/DPAPI, macOS Keychain, Linux Secret Service.
- [ ] При недоступном хранилище предложить явно согласованный временный сеанс без сохранения.
- [ ] Удаление профиля с очисткой секретов; обработка повреждённых и слишком больших файлов.
- [ ] Обнаружение установленной AmneziaVPN как отдельная опциональная функция; без обхода защиты.
Критерий выхода: импорт/удаление и перезапуск приложения проверены; секреты отсутствуют в Git и диагностике.

## M3 — Управление процессами и IPC

Зависит от M1–M2.
- [ ] Реализовать versioned JSON Lines по stdin/stdout между Flutter и Go.
- [ ] Ввести requestId, ограничения длины, таймауты, capabilities и согласование версии.
- [ ] start/stop/status, события состояния и структурированные безопасные ошибки.
- [ ] Запуск строго по абсолютному пути доверенного бинарника без shell; проверка версии/hash.
- [ ] Определить передачу конфигурации без ключей в аргументах; убрать временные файлы либо защитить ACL/0600.
- [ ] Проверить занятые порты, двойной запуск, параллельные команды и повторный stop.
- [ ] Отключать туннель при закрытии UI/EOF, отмене и аварии; дочерние процессы не оставлять.
- [ ] Windows Job Object и завершение дерева; Unix группы процессов, SIGTERM и ограниченный timeout.
- [ ] Отличать старт процесса, готовность listener и подтверждённую сетевую доступность.
Критерий выхода: 100 циклов start/stop без утечек процессов/портов; аварийные сценарии покрыты.

## M4 — Пользовательский интерфейс

Зависит от M2–M3.
- [ ] Разделы подключения, профилей, настроек и очищенной диагностики.
- [ ] Состояния disconnected/starting/running/stopping/error с действиями восстановления.
- [ ] Сохранение темы, системная тема, доступная клавиатурная навигация и focus.
- [ ] Reduced motion для всех переходов, отсутствие бесконечных декоративных анимаций.
- [ ] Tray и явная политика закрытия; никакого неявного фонового подключения.
- [ ] Настройка портов с проверкой loopback, понятные причины ошибок.
- [ ] Проверка длинных текстов, маленьких окон, screen reader и DPI.
Критерий выхода: все действия доступны с клавиатуры, состояния соответствуют движку, нет переполнений.

## M5 — Защита и интеграционные проверки

Зависит от M3–M4.
- [ ] Проверить отсутствие прямого fallback при падении туннеля.
- [ ] Проверить DNS-утечки с удалённым разрешением SOCKS5 hostname и HTTP CONNECT.
- [ ] Предупреждать, что приложения вне прокси не защищены.
- [ ] Fuzz-тесты разбора конфигурации и IPC, лимиты соединений/памяти/таймаутов.
- [ ] Redaction тесты ключей, экспортов и адресов; диагностика только по явному действию.
- [ ] Проверка supply chain, обновлений и подмены executable.
- [ ] Прогоны на реальных ОС и управляемом VPN-сервере, включая sleep/resume и смену сети.
Критерий выхода: протокол испытаний с версиями ОС/backend и воспроизводимыми результатами.

## M6 — Поставка (первая beta)

Зависит от M5.
- [ ] Windows installer и подпись; macOS bundle, подпись и notarization; Linux пакет/AppImage.
- [ ] Совместная упаковка UI/backend с проверкой архитектуры CPU и путей с Unicode/пробелами.
- [ ] Решить macOS sandbox/entitlements до интеграции subprocess и сетевого доступа.
- [ ] Release workflow только по тегу; checksums, лицензии, SBOM, release notes.
- [ ] Проверить установку, обновление, откат и удаление на чистых машинах.
- [ ] Опубликовать сайт и изменить GitHub About только по отдельному запросу.
Критерий выхода: подписанные, испытанные пакеты; ограничения перечислены в release notes.
