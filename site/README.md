# Сайт Amnezia Proxy Manager

Один экран на обычном настольном дисплее. На небольших экранах содержимое
перестраивается вертикально; если высоты не хватает, прокрутка сохраняет доступ
к кнопкам и ссылкам. HTML, CSS и JavaScript без сборщика и серверной части.

- Выбранные логотип и SVG-пиктограммы варианта 03.
- Nunito, Nunito Sans и JetBrains Mono с локальными файлами и SIL OFL.
- Переключение ОС с движущейся подложкой и появлением текста кнопки.
- Светлая/тёмная тема, сохранение выбора только в локальном хранилище браузера.
- Анимированная схема двух режимов, явно обозначенная иллюстрацией.
- Поддержка `prefers-reduced-motion`, клавиатуры и видимого фокуса.
- Ссылки на постоянные имена установщиков GitHub Releases; номер последнего
  стабильного выпуска берётся из публичного GitHub API. При ошибке остаётся
  обычная ссылка. Шрифты и оформление от сторонних серверов не зависят.

## Просмотр

Из корня репозитория:

```sh
python -m http.server 8765 --directory site
```

Откройте http://localhost:8765/. Публикация — `.github/workflows/pages.yml`.
Адрес: https://hecatoncheir.github.io/amnezia-proxy-manager/.

Общие исходники оформления находятся в `apps/desktop/assets/`. В `site/assets/`
хранится их копия для самостоятельной публикации статической папки. При замене
оформления обновите обе копии; шрифты должны сопровождаться лицензиями.
